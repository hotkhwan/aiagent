# AI Agent World app — Support

The app controls an aiagent server you run on your own computer.

## Getting started

1. Install the server: see the [README](../README.md).
2. Open the server's web page and sign in with your token.
3. Press **📱 App** at the top: it shows a QR.
4. In the app, press **Scan QR** (or copy the code and use *Paste a code instead*).

## Common questions

- **"The server refused this token"** — the token was revoked or reissued.
  Remove the profile and add it again with a new code.
- **No notifications** — allow notifications for AI Agent World in Settings,
  and make sure the server runs v0.28.0 or later.
- **Several servers or roles** — the free plan keeps one profile; the
  multi-profile subscription keeps up to 20 and switches between them.
- **Cancel the subscription** — Settings › Apple ID › Subscriptions on iPhone,
  or Play Store › Subscriptions on Android.
