# AI Agent Cyberpunk assets — initial concept batch

This package contains 8 empty room JPGs (1600x1000), 8 sky PNGs (800x500), 8 sign plaques with exact dimensions, and 8 24x24 SVG icons. These assets are new programmatically drawn concept artwork, not AI image-generator outputs. No props, sprites, town/exterior assets, or UI screens are included. Room backgrounds must remain empty so runtime props and agents can be composited. Code changes are still needed for Sessions screen and Workflow Town. Do not label these production ready until visual review and Go tests pass.
