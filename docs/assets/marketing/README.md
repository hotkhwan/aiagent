**Where they come from.** Every screen in these images is a screenshot of a
real aiagent instance (v0.31.1 web build) running fictional demo sessions — a
"shop" project with four Claude Code sessions and one Codex session. Nothing
in the interface was drawn or generated. The machine name was replaced with
`my-server` and one stale error box from the demo's outbox was hidden before
capture. No tokens, pairing QR codes or real paths appear.

sprites by scripts kept outside this repository.
