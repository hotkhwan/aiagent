# Asset manifest — what was generated, with what, and from what prompt

Every image generated by an agent is recorded here before it is considered,
whether or not it ships. Two reasons: `ASSETS.md` says provenance has to be
established before a public release, and a prompt that produced something good
is worth being able to run again.

Nothing in this file is in `web/assets` unless its row says **installed**.

---

## 2026-11-07 — `house-kcmd`, attempt 1

| | |
|---|---|
| Target | `house-kcmd.png`, the agcmd house on the village map |
| Needed | 660px wide, cut out, per `VILLAGE_BRIEF.md` |
| Tool | Canva `generate-image` (owner's Canva account, consumes their credits) |
| Output | 1456x1088 JPEG, Canva media `MAHaPFA55Fs` |
| Status | **not installed** — see below |

Prompt, verbatim:

> A single isometric cyberpunk pavilion building for a game map, standing
> alone on a plain flat mid-grey background with nothing else in the image.
> Neon-lit glass and dark metal structure, cherry-blossom accents, glowing
> teal and green neon trim and signage, warm lit interior visible through
> large windows showing a terminal workstation with monitors. Night lighting,
> rich painted illustration with soft shading and a clear light direction,
> chunky stylised proportions, heavy clean edges. The whole building fits
> inside the frame with empty grey margin all around it. No text, no logos,
> no characters, no ground scenery, no sky.

**Why it was not installed.** It is in the right world — isometric, neon,
sakura, night — and large enough. But it reads as a **sealed vault or crate**,
not a building someone works in: the front is panels rather than windows, and
there is no interior to see. The village's whole point is that you can tell
the houses apart and that each one looks lived in; the mockup's pavilions are
mostly glass with a lit room inside and a name sign over the door.

Asking again with a stronger prompt is possible, and so is the alternative
that has worked better every time so far: the owner generates the set
externally and sends the files, which `tools/propprep` then prepares. Each
attempt here spends the owner's Canva credits, so this one stops at one.
